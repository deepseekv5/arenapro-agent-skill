01

这个 Skill 是什么

一句话：把 ArenaPro 官方中文文档变成 AI Agent 可以按需检索、带出处引用的工作知识库。它不是文档的复制粘贴展示，而是一份带清单、索引与使用规程的 Skill——Agent 装载后知道「先查文档，再作答、再写码」。

构成 = SKILL.md（触发条件与检索规程）+ scripts/search.py（零依赖检索）+ references/docs/（85 篇官方文档转化件 + 自写导航索引 + 2 篇原创指南）· 详见 Skill 总览

全量、结构化

对应官方站点导航层级组织：入门、开发工作流、进阶主题、组件框架、React UI、与引擎差异、配置权限、MCP、社区。保留原文标题层级、代码块与内部链接关系。

按需检索，不塞满上下文

Skill 清单先给 Agent 一张主题地图，再按问题定位到具体 md 文件读取。问 HMR 就查 HMR，不必带着全部文档陪跑。

答案可溯源

回答附带文档路径出处，写出的代码示例以官方 API 章节为准。出错时人和 Agent 都能回到原文核对。

02

给谁用

只要你搭配的编程 Agent 需要理解 ArenaPro，这个 Skill 就是它的说明书。

CREATOR

神岛创作者

在 VSCode 里配 Copilot 类 Agent 写玩法逻辑时，让 Agent 基于真实 API 而非猜测来生成组件、React UI 与配置代码。

AGENT

AI 编程助手 / 数字员工

作为 QoderWake 等 Agent 平台的技能装载，用于答疑群、工单机器人、内部知识助手等需要 ArenaPro 领域知识的场景。

TEAM

团队与工具作者

围绕 ArenaPro 做脚手架、CI 或 MCP 工具链的团队，可以直接复用这套 md 知识库作为机器可读的事实源。

03

装上之后，Agent 能做什么

能力边界就是文档边界——下面每一项都对应 docs-md 里的真实章节。

  • C1

    带出处的文档问答

    「权限怎么授权？」「dao3Cfg 有哪些字段？」——直接定位 authority / dao3Cfg 章节作答并附文件路径。

  • C2

    按官方 API 写组件代码

    Component、NodeSystem、装饰器、生命周期、事件节点、时间回溯系统——生成的代码有章节依据。

  • C3

    编写游戏内 React UI

    环境搭建、XML 语法、Hooks、事件处理、refs、多组件组织等 reactGuide 全章可检索。

  • C4

    指导完整开发工作流

    从安装环境、创建项目、连接云端，到编译原理、HMR 热更新与断点调试的分步指引。

  • C5

    讲清与引擎的差异

    存储、资源路径、对话框、自定义实体、远程通道、体素等 difference 章节逐条对照。

  • C6

    NPM 生态实践建议

    本地包、发布共享包，以及 zod、remeda、gl-matrix、simplex-noise 等在 ArenaPro 下的用法。

  • C7

    自动化测试与规范

    进阶主题中的测试、Lint 与格式化、代码复用与通信约定等最佳实践可直接引用。

  • C8

    MCP 协同

    结合官方 MCP 工具章节，把知识库问答模式接入支持 MCP 的客户端。

04

安装与使用

复制下面这段，贴给你身边的 AI agent 即可自动安装——下载、放置、自检全部由它完成，你不需要碰命令行。

INSTALL.md 原文 Skill 包直接下载（zip） Release 页
手动分步安装与自检清单（完整信息层次，点开查看）

路径 A · git clone

git clone https://github.com/deepseekv5/arenapro-agent-skill.git
cp -r arenapro-agent-skill/skill/arenapro-docs ~/.qoder/skills/   # 或项目级 .qoder/skills/

路径 B · 免 git 下载 zip

下载上方 Release zip，解压得到 arenapro-docs/，整个目录放进技能目录即可。

安装自检

  1. 技能目录内存在 SKILL.md、scripts/search.py、references/docs/（89 篇 md）。
  2. python3 scripts/search.py --toc 能列出文档目录。
  3. 关键词检索（如 HMR、npm 包）返回命中文件与排名。
  4. 直接向 Agent 提问 ArenaPro 开发问题，回答自带文档出处。

保持文档最新

文档目录按优先级解析：--docs-dir 参数 > 环境变量 ARENAPRO_DOCS_DIR > Skill 内置 references/docs/ > 项目库 docs-md/。官方文档站更新后运行 scripts/refresh_docs.py 刷新，无需重装 Skill。

以上口径以仓库 INSTALL.md 为单一事实源。

05

背景：ArenaPro 是什么

这个 Skill 服务的对象——神岛（Dao3 Arena）平台的官方开发工具链。

ArenaPro Creator 是面向神岛游戏平台的 VSCode 扩展与开发方案：用 TypeScript 写玩法逻辑，保存即同步到云端，HMR 实时预览，Alt+Q 完整构建，断点调试可逐帧回溯；配套组件化框架（@dao3fun/component）、游戏内 React UI（@dao3fun/react）、NPM 包生态与 MCP 工具接入。

环境门槛很低：VS Code v1.9.0+、Node.js v20+，在扩展市场搜索 ArenaPro Creator 安装即可创建第一个项目。

  1. WORKFLOW

    创建项目

    插件脚手架生成规范 TypeScript 工程。

  2. COMPILE

    编译打包

    Webpack 翻译 TS、合并资源，产出可上传成品。

  3. SYNC

    云端连接

    保存即同步神岛环境，本地线上不分家。

  4. DEBUG

    调试热更

    HMR 实时预览 + 断点回溯验证每次改动。
